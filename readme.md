# LuaTools for Millennium

Add Lua script support and game fixes to your Steam games — right from the Steam store page. Free for everyone.

## Requirements

- [Millennium](https://github.com/SteamClientHomebrew/Millennium) (Steam Homebrew) installed and running
- The [LuaTools desktop app](https://discord.gg/XeTECUuqb) installed (the plugin launches it automatically if it's closed)

## Install

1. Download the latest [release](../../releases)
2. Extract the folder into your Millennium plugins directory:
   `Steam/millennium/plugins/luatools-millennium`
3. Restart Steam
4. Open any game's store page — the **LuaTools** button appears there

## Usage

1. Open the game's store page in Steam
2. Click the **LuaTools** button
3. Pick a source and click it
4. Wait for it to finish — restart Steam if asked

## Features

- **Store-Page Quick Menu**: One-click install/remove, update checks, and game status.
- **In-Plugin Settings Manager**: Live theme switcher with 12 palettes, 30+ interface languages, and fast download mode.
- **Live Update Checker**: Checks GitHub releases directly from inside Steam.
- **Gamepad Navigation**: Full controller support for Steam Big Picture / Steam Deck.
